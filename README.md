# Vibetour

Vibetour - прогрессивное турагенство с маршрутами по всему миру.

Проект реализует:
- Панель администратора для создания и редактирования туров
- ИИ агент, который подбирает мероприятия для тура за администратора, избавляя последнего от поиска этих мероприятий

## Запуск
```bash
# В одном окне
cd /frontend
npm install
npm run dev

# В другом окне
go mod tidy
go mod cmd/api/main.go
```
